InspireFace

Detect, track and compare faces in your own application.

Run your first exampleSource on GitHub

Images and video

Detect faces in a photograph, track them across frames, and read landmarks, pose and quality from the same session.

Choose your API

Use C, C++, Python, Java, Android, HarmonyOS ArkTS, Objective-C or Swift. Enable the extra models your application needs.

Choose your deployment

Start on CPU, then select a matching SDK and model pack for Apple CoreML, Rockchip NPU or NVIDIA TensorRT.
