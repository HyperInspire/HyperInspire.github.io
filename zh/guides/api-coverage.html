InspireCV 图像处理

InspireCV 是独立的 C++ 库。指南介绍 Image 读写与常用操作、浮点图像、Task 变换与张量、错误处理、连续帧内存复用和可选 CUDA 处理。它的 PixelFormat、旋转和 Pipeline 类型，与 InspireFace C API 及 FrameProcess 分别定义。

完整公开接口可查看 InspireFace C 声明、原生 C++ 头文件、Objective-C 头文件、Swift 封装、Python 封装、HarmonyOS ArkTS 导出和 InspireCV 头文件。接入某个发布包时，以随包头文件为准。

接入说明

  • Java 的 long 句柄需要显式释放；结果中的 ByteBuffer 可能借用原生内存，Java 对象仍在并不代表底层数据仍有效。见 Java 生命周期。
  • Android 1.2.4.post1 已包含抓拍与快照。高层返回的数组和 token 是 Java 自有副本，Native 缓冲区仍遵循 C 的借用规则。创建与释放图像流必须使用同一 API 层，见 Android 生命周期。
  • 复制 C++ 人脸结果向量可以保留几何信息和 token。后续还要提取特征时，同时保留对应帧的像素。
  • ArkTS 跟踪快照用 session.releaseFaceResult() 释放；图像流、位图、抓拍会话和会话使用完后调用 close()。各封装对象留在创建它的 worker 中使用。
  • 标准 HarmonyOS HAR 使用 MNN CPU 推理，接收原始图像缓冲区。文件解码和图像显示使用 HarmonyOS 系统 API。
  • Objective-C 与 Swift 封装原生句柄。ARC 管理封装对象，借用的人脸、特征与像素指针仍受原生结果生命周期限制。
  • CoreML、TensorRT、RKNN、RGA 和 CUDA 预处理需要匹配的 SDK 构建与运行环境，部署步骤见对应平台指南。
