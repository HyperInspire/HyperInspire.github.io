图片与视频

检测照片中的人脸，在视频中持续跟踪，并通过同一个会话获取关键点、姿态和质量结果。

按需接入

使用 C、C++、Python、Java、Android、HarmonyOS ArkTS、Objective-C 或 Swift，按应用需要启用额外模型。

选择部署环境

先在 CPU 上跑通，再为 Apple CoreML、Rockchip NPU 或 NVIDIA TensorRT 选择匹配的 SDK 和模型包。
